상세한 설명

Converts the player-facing "note speed" dial into the raw seconds the gameplay code actually uses. Gameplay stays in seconds (NoteSettings is untouched); only the settings UI speaks in these dial values.

Dial value: 1.00 ~ 20.00 in 0.25 steps (keyboard entry allows any 0.01 in range). Time curve : LINEAR between the two anchors

  • v = 1 -> 1.00 s (slowest)
  • v = 20 -> 0.20 s (fastest) Linear keeps the step size uniform (~42 ms per dial unit) so the whole 1.0~0.2 s band gets dense, evenly-spaced options.
