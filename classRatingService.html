상세한 설명

Player rating = average of the Best 15 chart ratings (missing slots count as 0).

Per-chart rating is piecewise linear over acc = score / 1,000 (percent): acc 80 or below → 0 acc 80 ~ 95 → level × g(acc), g: 85→0.20, 90→0.50, 92.5→0.70, 95→1.00 acc 95 ~ 100 → level + mod(acc), mod: 97→+1.5, 99→+2.5 (S, cap), 100→+2.6 (AP) So 95% == the chart's level ("적정"), and the bonus above it is level-independent.

Data source is the player's verified best scores:

  • SongScanner supplies every chart's level + chartHash.
  • LocalScoreSaveService supplies the best score per chartHash for the current SaveIdentity. Auto-play runs are excluded at save time in ResultsUI (best score / leaderboard upload only happen when AutoPlay is OFF), so every score feeding the rating is the same verified data that is pushed to the Steam leaderboard.

Only Ranked charts (server registry) count toward the rating; others keep local records but are excluded here (see ChartRegistryService).
