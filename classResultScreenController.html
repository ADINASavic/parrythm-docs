상세한 설명

UI Toolkit port of the ingame result screen (ResultScreen.uxml, shared ResultTheme.uss + OutgameTheme.uss). Same public surface as the legacy Canvas ResultsUI (SetTotalNotes / ShowAsync) so GameBootstrap / ChartEndWatcher only need their field type repointed at this component in the Inspector — see UITOOLKIT_PORT.md for scene wiring.

Simplified vs the HTML mock: Friends tab has no real data source (no Steam-friends-scoped query anywhere in this project) and shows an honest "not available" note instead of faked rows — Global/Local are both real (Global = LeaderboardServiceProvider.Current, Local = a LocalLeaderboardSaveService instance directly, bypassing Steam). No tier badge (SongMeta has no tier field). The mods tag reads the active runtime modifiers. "Your rank" is derived by scanning the fetched top N for the local player's id (SaveIdentity.CurrentId) rather than fabricated — shows "not in top N" when absent.
