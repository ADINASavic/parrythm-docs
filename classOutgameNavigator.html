OutgameNavigator 클래스 참조

Minimal screen switcher for the UI Toolkit outgame port. Each screen controller registers its root VisualElement under a key ("title", "songselect", "settings"); Show() flips which one is displayed. GameObjects stay active (so each controller's OnEnable wires up once) — only the root element's display is toggled. 더 자세히 ...
